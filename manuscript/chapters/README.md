# Chapters — not yet drafted

Use [the chapter brief template](CHAPTER_TEMPLATE.md) for planning and then create numbered files such as `01-working-title.md` when approved. Each prose chapter should be clean and readable independently; editorial metadata and encounter placement belong in a separate brief or header that can be stripped from narration exports.

The full coverage ledger is in [Encounter atlas](../../story/ENCOUNTER_ATLAS.md). A chapter is not complete until its event placement, continuity and source relationships have been checked.
