## Scope and method

The prior text-overlap script flagged **24** unusually low single-paragraph matches. Separately, **33** game descriptions changed since the literary baseline (IDs **20158–20190**). Exactly **three IDs belong to both sets: 20164, 20172 and 20185**. The union therefore contains **54 distinct game IDs**. For this package, the **actual current game source text** was read and compared against relevant **manuscript passages**, looking for the distinct event, person, imagery, action, place, mode and material clues rather than merely a title or percentage match. Where the automatic locator pointed to an unrelated paragraph, surrounding/later prose was located manually.

**Review nomenclature:** **“AI-targeted scene hook present”** means a specific source encounter has an identifiable literary event or documented adaptation in an inspected passage, *not* every line, all narrative context, world lore, audiobook rhythm or human approval independently checked. **“Corrected”** means an actual prose file was changed; **“Mode-specific”** means nonliteral adaptation is deliberately retained. The **149 unselected ID passages** and the continuous full manuscript review remain OPEN.
