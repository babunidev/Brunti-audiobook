# Documentation standard

This guide follows the [Morkahja documentation convention](https://github.com/babunidev/Morkahja/blob/main/docs/DOCUMENTATION.md).

## Voice and attribution

In public-facing project narratives, write naturally from Babuni's **first-person creative perspective**. Use "I" or "my" within sentences, but **do not begin narrative sentences with "I" or "My"**. Factual tables, instructions and changelogs can be neutral. Call Babuni the **human creative**, not the website or software account.

Whenever AI contributes, identify the product/tool and confirmed model where possible. State whether it reviewed, categorized, proposed, drafted, wrote or tested; do not credit AI-created documents as manually drafted by Babuni, or assign the original creative direction to AI.

## Proper responsibilities

- `README.md`: accessible entry point and present status.
- `CONCEPT.md`: creative brief and boundaries.
- `story/`: literary proposals, people, structural planning, encounter coverage.
- `manuscript/chapters/`: eventual actual chapter prose and draft template.
- `production/`: narration/audio workflow.
- `docs/SOURCES.md`: pinned provenance and authoritative source hierarchy.
- `docs/CONTENT.md`: categorization method and cross-reference rules.
- `docs/DECISIONS.md`: direction, approved choices and pending proposals.
- `docs/DEVLOG.md`: concise dated creative journal and verification limits.
- `CHANGELOG.md`: actual repository changes.
- `ROADMAP.md`: completed versus outstanding phases.

## Evidence categories

Keep **human creative direction**, **AI proposal**, **explicit decision**, **manuscript draft**, **editorial review**, **audio rendering**, and **publication** separate. An encounter index proves source coverage, not story placement. Inspect the current repository and specific source revision before rewriting or marking statuses.

Use clear Markdown with working relative links. Document any lore contradiction rather than manufacturing certainty. Keep personal data, secrets, unauthorized media and third-party credits intact.
